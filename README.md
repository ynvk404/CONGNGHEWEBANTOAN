# BÀI TẬP CÔNG NGHỆ WEB

## Giới thiệu
Mã nguồn các bài tập môn **Công nghệ Web**, tổ chức theo từng thư mục (Bai4, Bai5, Bai6, …) với cấu trúc PHP, HTML, CSS.

## Yêu cầu
- **XAMPP** hoặc tương đương (Apache + PHP + MySQL).  
- Sử dụng thư mục `htdocs` mặc định của XAMPP.

## Cách chạy
1. Tải toàn bộ mã nguồn về.  
2. Đổi tên thành **BAITAPWEB**.  
3. Đặt vào thư mục: xampp/htdocs/BAITAPWEB
4. Truy cập trên trình duyệt: http://localhost/BAITAPWEB
